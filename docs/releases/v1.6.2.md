# Codex Dream Skin v1.6.2

**中文** · [English](https://github.com/xxue-z/Codex-Dream-Skin/blob/v1.6.2/docs/releases/v1.6.2-en.md)

本次更新把动态主题的控制集中到顶层“动态主题”菜单，已保存主题改为直接点击名称应用，并修复 Windows PowerShell 5.1 下“应用或重新应用”无法停止旧后台进程的问题。

## 新增功能

- **动态主题菜单**：Windows 托盘和 macOS 菜单栏新增顶层“动态主题”，集中提供当前活动动态主题的静音/暂停、当前视频文件夹、自动发现与 1/2/5/10/30 秒检测间隔、自定义/恢复视频文件夹、0–100% 遮罩透明度滑块，以及更换海报、恢复默认海报、打开视频文件夹和重新扫描视频。
- **视频文件夹设置**：设置保存在独立的 `video-settings.json`；关闭自动发现后只在手动“重新扫描视频”时刷新，自定义文件夹切换后立即生效并从头播放。
- **遮罩透明度**：滑块 0% 对应原“强遮罩”、100% 对应原“软遮罩”，升级后默认视觉不变。

## 修复与改进

- **已保存主题**：Windows 和 macOS 都改为平铺列表，直接点击主题名称即应用；动态主题不再展开只有“应用”的子菜单。
- **Windows 应用/重新应用**：修复 Windows PowerShell 5.1 将 `injectorStartedAt` 解析为日期对象后，旧后台进程身份校验失败、导致无法停止旧 watcher 的问题。现在会规范化时间格式并按 2 秒容差比较，同时保留 PID、可执行文件、命令行、端口和浏览器 ID 校验。
- **非动态主题**：当前主题没有动态背景时，顶层“动态主题”里的静音/暂停显示为不可用，不会误改其他偏好。

## 升级与使用

使用新安装包覆盖安装即可，已保存主题、视频、海报和本机偏好会保留。动态主题菜单里的静音/暂停作用于当前活动主题；播放列表主题使用 `video-playlist.json`，Skin API 2 主题使用按主题保存的 `theme-video-preferences.json`。
