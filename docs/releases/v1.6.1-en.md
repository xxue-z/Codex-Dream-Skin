# Codex Dream Skin v1.6.1

[中文](https://github.com/xxue-z/Codex-Dream-Skin/blob/v1.6.1/docs/releases/v1.6.1.md) · **English**

This release extends dynamic backgrounds to a local video playlist on the default theme and adds a hot-swappable static poster. It also fixes playlist pause/mute state, repeated reloads on non-playlist themes, and the hidden-window verification delay.

## New features

- **Default-theme video playlist**: Put `.mp4` / `.webm` files in `%LOCALAPPDATA%\CodexDreamSkin\videos\` on Windows or `~/Library/Application Support/CodexDreamSkinStudio/videos/` on macOS. The default theme plays them in filename order, loops with hard cuts, starts muted, and resumes the last segment and position.
- **Hot-swappable poster**: The default theme keeps the original Arina Hashimoto background. Replace `...\poster.jpeg` or use “Change poster…” in the default-theme submenu; changes apply within 1–2 seconds. Invalid files keep the last good poster, and deleting the override restores the bundled background.
- **Default-theme submenu**: Windows tray and macOS menu bar expose Apply / Mute / Pause / Reduce scrim / Change poster… / Restore default poster / Open videos folder / Rescan videos at the same level.
- **MP4 dynamic backgrounds**: Skin API 2 packs still support one `background.mp4` (H.264 8-bit, ≤16 MiB, 2–20 seconds, ≤1920×1080, muted by default, paused while the window is hidden). v1.6.1 includes the 1.6.0 dynamic-background work and this default-theme playlist, and is the first public release containing both.

## Fixes and improvements

- **Playlist pause/mute**: Pause now shows its checkmark and resumes on the next click; Mute only changes audio. Preferences persist correctly.
- **Non-playlist themes**: The `videos/` folder no longer triggers a theme reload every 1.2 seconds when the active theme is not the default playlist theme.
- **Hidden-window verification**: Theme switches now return from the hidden-session check in about one second and show the restart prompt promptly instead of waiting the full five seconds.
- **Public preset hash**: The Gothic public preset metadata is restored to its reviewed hash, so release builds no longer fail on preset integrity checks.

## Upgrading and usage

- Install the new package over the existing installation; saved themes and local preferences are preserved.
- Videos and posters are read only from the fixed local directories. Nothing is uploaded, no listening port is opened, and the official `app.asar` is never modified.
- The official ZIP contract is unchanged: official packs still allow exactly one `background.mp4`, and `videos/` is not part of official packs.
- The macOS default theme is Gothic Void Crusade; the Windows default theme is Arina Hashimoto. The playlist is enabled only on each platform's default theme.
