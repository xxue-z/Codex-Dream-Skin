# Codex Dream Skin v1.6.0

[中文](https://github.com/Fei-Away/Codex-Dream-Skin/blob/v1.6.0/docs/releases/v1.6.0.md) · **English**

This release adds dynamic backgrounds to theme packs. Authors can ship a short MP4 alongside the static poster so the window wallpaper plays muted and looped; environments that cannot play it fall back to the poster.

## New

- **MP4 dynamic backgrounds**: A Skin API 2 pack may include one optional `background.mp4`. The video is rendered as the wallpaper layer and never inside messages, code blocks or toolbars.
- **Poster fallback**: `image` is still required and remains the loading placeholder, decode-failure fallback and reduced-motion substitute. Static packs and existing API 1 themes keep their current behavior.
- **Automatic power saving**: Decoding pauses while the document is hidden. Reduced-motion or a local preference that disables dynamic backgrounds shows the poster only.
- **Strict validation**: Videos must be H.264 8-bit, carry at most one audio track, and be non-fragmented MP4, at most 16 MiB, 2-20 seconds and no larger than 1920x1080. They start muted by default; dynamic saved themes expose checkable Mute and Pause items in the Windows tray (checked means muted or paused). The container, tracks, codec, dimensions and duration are revalidated on import and on every apply.
- **Platform parity**: Windows and macOS share the same bounded MP4 parser, error codes and renderer path.

## Compatibility

- Existing API 1 packs need no changes and continue to import and apply normally.
- API 2 packs require client **1.6.0 or newer**. Older clients reject them explicitly instead of silently ignoring the video.
- This release does not transcode. Authors must provide a compliant MP4; Studio and server-side upload/review support will follow.

## Upgrading

Install the new package over the existing installation. Saved themes and local preferences are preserved. Dynamic backgrounds are enabled by default and can be disabled from the native settings entry once it ships.
