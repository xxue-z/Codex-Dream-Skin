# Codex Dream Skin v1.6.2

[中文](https://github.com/xxue-z/Codex-Dream-Skin/blob/v1.6.2/docs/releases/v1.6.2.md) · **English**

This update consolidates dynamic-theme controls into a top-level Dynamic themes menu, makes every saved theme apply directly from its name, and fixes Apply/Reapply failing to stop the old watcher under Windows PowerShell 5.1.

## New features

- **Dynamic themes menu:** Windows tray and macOS menu bar now expose a top-level Dynamic themes menu with Mute/Pause for the active dynamic theme, the current videos folder, auto-detect with a 1/2/5/10/30-second interval, change/restore videos folder, a 0-100% scrim transparency slider, and Change poster, Restore default poster, Open videos folder and Rescan videos.
- **Videos folder settings:** Settings live in `video-settings.json`. With auto-detect off, files are picked up only by Rescan videos; a custom folder applies immediately and restarts the playlist from the first file.
- **Scrim transparency:** 0% matches the former strong anchors and 100% the former soft anchors, so an upgrade keeps the current look.

## Fixes and improvements

- **Saved themes:** Windows and macOS now show a flat list; clicking a theme name applies it. Dynamic themes no longer expand into a one-item Apply submenu.
- **Windows Apply/Reapply:** Windows PowerShell 5.1 parses `injectorStartedAt` into a date object, which made the old watcher identity check fail and prevented Apply from stopping it. The recorded instant is now normalized and compared with a two-second tolerance while keeping the PID, executable, command line, port and browser-ID checks.
- **Non-dynamic themes:** When the active theme has no dynamic background, the Dynamic themes menu disables Mute/Pause instead of changing unrelated preferences.

## Upgrading and usage

Install over the previous version; saved themes, videos, posters and local preferences are kept. Mute/Pause in the Dynamic themes menu act on the active theme: the playlist theme uses `video-playlist.json`, while Skin API 2 themes use their per-theme `theme-video-preferences.json`.
