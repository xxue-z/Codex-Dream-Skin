# Codex Dream Skin v1.6.3

[中文](https://github.com/xxue-z/Codex-Dream-Skin/blob/v1.6.3/docs/releases/v1.6.3.md) · **English**

This update fixes theme application on Codex 26.1120 and prevents the assistant reply column from being painted as a solid card. On Windows, applying a theme also restores a minimized Codex window before verification.

## Fixes and improvements

- **Windows / Codex 26.1120**: The top bar now renders as `<header data-app-shell-titlebar>`, so the old header anchor no longer matched, verification failed and the theme rolled back. The selector now accepts the new titlebar as well as legacy headers.
- **Windows**: Applying a theme restarts Codex. If the new window stays minimized, verification sees `document.hidden` and rolls back. Startup now restores and foregrounds the real top-level window with Win32 before continuing verification.
- **macOS / Windows**: Codex 26.1120 puts `data-local-conversation-final-assistant` on the full-width assistant wrapper. A community theme's `[data-ds-part="message"]` background painted the entire reply column as a solid card. User bubbles keep their surface; the assistant reply column is transparent again so the wallpaper shows through the chat area.

## Upgrading and usage

Install over the previous version; saved themes, backgrounds, videos, posters and local preferences are kept. Per-theme transparency still applies; raise it if you want more wallpaper visible. Apply/Reapply restarts Codex and briefly interrupts the current session.
