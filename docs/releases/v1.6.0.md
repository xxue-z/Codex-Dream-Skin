# Codex Dream Skin v1.6.0

**中文** · [English](https://github.com/Fei-Away/Codex-Dream-Skin/blob/v1.6.0/docs/releases/v1.6.0-en.md)

本次更新加入主题包动态背景。主题作者可以在静态海报之外提供一个短 MP4，让窗口壁纸静音循环播放；不支持视频的环境会自动回退到海报。

## 新增

- **MP4 动态背景**：Skin API 2 主题包可以携带一个可选的 `background.mp4`。视频作为壁纸层播放，不进入消息卡片、代码块或工具栏。
- **海报回退**：`image` 仍是必填海报，负责加载占位、解码失败回退和“减少动态效果”替代；静态主题和旧版 API 1 主题行为不变。
- **自动省电**：窗口隐藏时暂停解码；系统开启“减少动态效果”或本机偏好关闭动态背景时只显示海报。
- **严格校验**：视频只接受 H.264 8-bit、无音轨、非分片 MP4，最大 16 MiB、2-20 秒、不超过 1920x1080；导入和每次应用都会重新校验容器、轨道、编码、尺寸和时长。
- **双端一致**：Windows 与 macOS 使用同一份有界 MP4 解析器、同一套错误码和同一条渲染路径。

## 兼容性

- 旧 API 1 主题无需修改，继续正常导入和应用。
- API 2 主题要求客户端 **1.6.0 或更高版本**；旧客户端会明确拒绝，不会静默忽略视频。
- 动态背景首版不执行转码。作者需要自行导出合规 MP4；Studio 与服务端的上传/审核支持会在后续更新中开放。

## 升级

使用新版安装包覆盖安装即可。已经保存的主题和本机偏好会保留；动态背景默认开启，可在后续的原生设置入口中关闭。
