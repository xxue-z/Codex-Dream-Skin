# Codex Dream Skin v1.6.1

**中文** · [English](https://github.com/xxue-z/Codex-Dream-Skin/blob/v1.6.1/docs/releases/v1.6.1-en.md)

本次更新把动态背景扩展到默认主题的本机视频播放列表，并加入可热替换的静态海报；同时修复播放列表暂停/静音状态、非播放列表主题反复重载和隐藏窗口校验等待的问题。

## 新增功能

- **默认主题视频播放列表**：在 Windows 的 `%LOCALAPPDATA%\CodexDreamSkin\videos\` 或 macOS 的 `~/Library/Application Support/CodexDreamSkinStudio/videos/` 放入 `.mp4` / `.webm`，默认主题会按文件名顺序循环播放，硬切、默认静音，并记住当前段和播放位置。
- **海报热替换**：默认主题保留桥本有菜原背景；把 JPEG 放到 `...\poster.jpeg`，或在默认主题子菜单选择“更换海报…”，1–2 秒内生效；无效文件保留上一张，删除后回退内置背景。
- **默认主题子菜单**：Windows 托盘和 macOS 菜单栏在默认主题下提供“应用 / 静音 / 暂停 / 降低遮罩 / 更换海报… / 恢复默认海报 / 打开视频文件夹 / 重新扫描视频”，同一级展示。
- **MP4 动态背景**：Skin API 2 主题包仍支持一个 `background.mp4`（H.264 8-bit、≤16 MiB、2–20 秒、≤1920×1080、默认静音、窗口隐藏时暂停）。v1.6.1 包含 1.6.0 动态背景能力与本次默认主题播放列表，是两者的首次公开发布。

## 修复与改进

- **播放列表暂停/静音**：修复暂停后勾选不显示、再次点击暂停不恢复、点击静音才恢复播放的问题；偏好会正确持久化。
- **非播放列表主题**：不再因为 `videos/` 目录 mtime 变化而每 1.2 秒重载主题，普通主题切换恢复即时响应。
- **隐藏窗口校验**：切换主题时若 Codex 窗口被隐藏/最小化，校验会在约 1 秒内返回并给出重启提示，不再固定等待 5 秒。
- **公开预设哈希**：恢复 Gothic 公开预设的原始 metadata，避免安装包构建因预设哈希变化而失败。

## 升级与使用

- 使用新安装包覆盖安装即可，已保存主题和本机偏好会保留。
- 视频和海报只从本机固定目录读取，不上传、不新增监听端口，也不修改官方 `app.asar`。
- 官方 ZIP 契约不变：正式主题包仍只允许一个 `background.mp4`，`videos/` 目录不会进入正式包。
- macOS 默认主题为 Gothic Void Crusade，Windows 默认主题为桥本有菜；播放列表只在各自默认主题下启用。
