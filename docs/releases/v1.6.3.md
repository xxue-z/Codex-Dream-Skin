# Codex Dream Skin v1.6.3

**中文** · [English](https://github.com/xxue-z/Codex-Dream-Skin/blob/v1.6.3/docs/releases/v1.6.3-en.md)

本次更新修复 Codex 26.1120 下主题应用失败和助手消息区域被实色覆盖的问题，Windows 端还会在应用主题时恢复被最小化的 Codex 窗口。

## 修复与改进

- **Windows / Codex 26.1120**：顶栏改为 `<header data-app-shell-titlebar>` 后，旧的 header 锚点不再命中，主题验证失败并回滚。现在选择器同时兼容新顶栏，应用主题不会再因缺少顶栏而失败。
- **Windows**：应用主题会重启 Codex；如果新窗口处于最小化状态，验证会读到 `document.hidden` 并回滚。现在验证前会用 Win32 恢复并置前真实窗口，再继续检查。
- **macOS / Windows**：Codex 26.1120 把 `data-local-conversation-final-assistant` 放在整块助手回复的外层容器上，社区主题的 `[data-ds-part="message"]` 背景会把整列回复涂成实色。现在只让用户消息气泡保留背景，助手回复列恢复透明，壁纸可以透过聊天区域显示。

## 升级与使用

使用新安装包覆盖安装即可，已保存主题、背景图、视频、海报和本机偏好会保留。主题透明度仍按主题偏好生效；想看到更多壁纸时可调高透明度。应用或重新应用主题会重启 Codex 并短暂中断当前会话。
